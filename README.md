Rapido Ride Analytics Dashboard

Project Overview

An interactive Power BI dashboard designed to analyze ride trends, booking value, payment methods, vehicle types, and ride status.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Key Dashboard Insights

- Analyzed monthly ride trends to identify changes in ride demand.
- Compared completed and cancelled rides to understand ride completion performance.
- Examined booking value across months and cities.
- Analyzed ride distribution by city, vehicle type, and payment method.
- Compared average ride duration across vehicle types.

Dashboard Features

- KPI cards for total rides, completed rides, cancelled rides, and booking value.
- Interactive slicers for vehicle type, year, and city.
- Visual analysis of ride trends and business performance.
